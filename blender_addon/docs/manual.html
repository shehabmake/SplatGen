SplatGen Prepare 5.3

Camera placement and dataset building for Blender 5.3.

Place cameras

Open the 3D View sidebar and choose SplatGen. Use Smart rig to calculate cameras for your scene, Manual to add the current view or create cameras from mesh faces, or Saved to load a bundled or personal camera rig. The queue lists the cameras that will render.

Use camera preview to review placement. Shared camera settings control focal length, sensor and clipping. Save arrangements as rigs to reuse them.

Check coverage

Run Check coverage before rendering. Inspect the coverage overlay and use the available repair tools where more views are needed. These scene overlays are part of camera preparation.

Build the dataset

  1. Save your .blend file.
  2. Choose the dataset output folder. With no explicit folder, the add-on uses a project folder beside the saved scene.
  3. Set your scene's render engine, resolution and samples, then choose image format and point sampling in Dataset settings.
  4. Run Build Dataset to render images, export cameras and generate the dataset point cloud. You can also run image rendering and point generation separately.
  5. Use the folder button to inspect the output. The dataset contains images, masks, depth, camera metadata and points3D.txt. Optional numerical metadata remains available.

Existing completed datasets are kept in separate build folders. Unfinished work can be continued through the existing recovery workflow. Stop cancels the active preparation operation.

What this edition includes

Smart and manual camera placement, saved rigs, camera review, coverage checks, image rendering, dataset export and dataset point generation.

What was removed

All training methods, trainer controls, Brush/SplatGen V2 executable, gsplat and PyTorch/CUDA packages, worker scripts, Gaussian-splat viewer and its import/export tools. The Dataset preview popover was also removed because it depended on that viewer.

Generating dataset points is not Gaussian-splat training. Use the resulting dataset in a separate training application if needed. This edition has no runtime installer or training activation control.

Preferences and support

Preferences control interface location, saved-rig directory, camera-list size and shortcuts. The bug-report button collects local preparation diagnostics. Enable only one SplatGen edition at a time, since the editions share operator identifiers.

Requires Blender 5.3.x on Windows x64. Uses Blender's own Python and NumPy; no extra packages are installed. See README.md and REMOVED_COMPONENTS.md beside this guide's parent folder for details.
